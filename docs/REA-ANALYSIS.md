## 구현 검증

- `npm test`: 실제 Three.js 객체를 사용하는 전투 규칙 테스트 5개 통과. 정령별 공격, 폭발 범위 피해, 중복 없는 성장, 클래식 보스 및 승리 조건, 무한 모드 주기, 일시 정지 중 능력 차단, 새 게임 초기화를 검증합니다.
- 브라우저 수동 자동화: 정령 도감에서 루미 선택 → 달빛 지역 → 게임 시작 → 자동 처치 → 대시·궁극기 → 일시 정지 → 모험 마무리 → 보상 및 기록 확인 → 새로고침 후 저장 유지 확인.
- 390×844 모바일 화면: 문서 너비 390px, 가로 넘침 없음. 조이스틱 드래그 시 `translate(25px, -15px)`, 해제 후 초기화 확인. 모바일 일시 정지 다이얼로그 표시 확인.
- 초기 카메라가 지면 아래를 비추는 문제를 수정하고, 전투 중 앞쪽 나무를 반투명하게 하여 시야를 확보했습니다.
- 보스까지의 3분 전체 플레이와 모바일 실제 기기 성능은 실측하지 않았습니다. 보스·성장·승리 분기는 시뮬레이션 테스트로 검증했습니다.
